# Memori Proyek: Radar Politik & Manajemen Reputasi (radar-ketapang)

## 1. 5W1H
- **What:** Aplikasi SaaS Single-Account "Radar Politik & Reframing" untuk intelijen media, deteksi isu/sentimen politik, dan respon narasi otomatis.
- **Who:** Tim Sukses (Timses), Tokoh Politik, Konsultan Politik, dan Tim Media Center.
- **Why:** Manajemen reputasi, mitigasi serangan kampanye hitam/isu negatif, dan penguatan narasi framing positif maupun defensif secara terukur.
- **Where:** Stack modern full-stack web: Laravel 13 + React + Inertia.js + Tailwind CSS.
- **When:** Pemantauan real-time (Real-time monitoring & crawling periodik).
- **How:** Autopilot crawling media & medsos -> Hermes AI API (analisis sentimen, ekstraksi entitas, & rekomendasi strategi) -> In-App Alert (notifikasi instan) -> 1-Click Script (generator narasi/klarifikasi/counter-issue siap rilis).

## 2. Arsitektur Sistem
- **Infrastruktur Container:** Full Docker & Docker Compose
  - `app`: Laravel 13 berjalan di atas Laravel Octane (FrankenPHP / Swoole) untuk performa tinggi & latency rendah (Port internal 8000).
  - `web`: Nginx Alpine sebagai Reverse Proxy, penangan SSL termination, dan direct static asset server (Port publik host: 8282).
  - `db`: MySQL 8.0 Engine (Port host: 33081).
  - `redis`: Redis Alpine untuk session driver, cache store, dan high-throughput background queue worker (Port host: 63811).
- **Backend:** Laravel 13 dengan PHP 8.4
  - Laravel Octane (FrankenPHP)
  - Laravel Sanctum (Token-based API Authentication)
  - Inertia.js Laravel Adapter v2
  - Redis Session & Queue Driver
- **Frontend:**
  - React 18/19
  - Inertia.js React
  - Tailwind CSS v4 (Cyber-Security / Command Center Dark Mode Theme)
  - Lucide React Icons
  - Vite 7 + Laravel Vite Plugin 2

  - **Catatan Teknis & Pitfalls:**
    - Single-Row Config: Menggunakan `TargetSetup::getOrCreate()` mencegah kekosongan data konfigurasi di sistem SaaS single-account.
    - Sanctum Token Persistence: Command `hermes:generate-token` menghapus token lama dengan nama sama (`hermes-agent-token`) sebelum membangkitkan token baru agar tabel token tetap bersih dan deterministik.
    - Validasi Webhook: Memverifikasi `news_id` exists, batas skor kecepatan (0-100), dan status nilai yang diizinkan untuk mencegah anomali data.
    - Recreate Container Octane: Saat memperbarui `APP_VERSION` atau environment variable lainnya, container Octane FrankenPHP wajib di-`force-recreate` agar nilai runtime terinjeksi baru, bukan sekadar `restart`.
